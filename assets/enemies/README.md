# 敵キャラクター画像

ChatGPTアプリなどで生成した透過PNGを、このフォルダに置いてください。

| ファイル名 | 敵 |
| --- | --- |
| goblin.png | 見張りゴブリン |
| mage.png | 月影の魔導士 |
| guardian.png | 古城の番人 |
| slime.png | 訓練スライム |

ファイル名は半角小文字で揃えます。透明背景・正方形・256×256pxを推奨します。画像が大きくても、ゲーム画面では縦横比を保って小さく表示します。

同じ名前のPNGを置くだけでコードの編集は不要です。実際の画像はまだ入っていません。未配置の敵は、これまでの仮SVGを表示します。

生成プロンプトは [enemy-image-prompt.txt](../../docs/enemy-image-prompt.txt)、参照先の設定は [enemy-graphics.js](../../js/enemy-graphics.js) です。新しい敵を追加する場合は、敵IDと画像参照をそろえて追加してください。
